{% header "h2", "Typography Guidelines" %}

Typography guidelines are designed to ensure legibility and hierarchy across platforms and screen sizes. Use 16px as a baseline for body text, with heading sizes scaled modularly (e.g., 1.25× or 1.333×) to create a balanced rhythm. Maintain adequate line height (typically 1.4–1.6×) and always prioritize accessibility by checking contrast and readability. Font weights should follow a simple structure: light or extra-light for large display text, semibold or medium for headings, and regular or medium for body text, buttons, and links.

{% header "h2", "Icons" %}

The Field Museum’s digital interfaces use the Material Symbols Sharp icon set to provide clear, consistent visual support for actions, navigation, status, and content types. This style was chosen for its crisp, angular shapes that remain legible at small sizes and align well with the Museum’s digital aesthetic.

Icons are used in the sharp, outlined style, with 200 and 300 weights being the most common across the interface. Standard icon sizes include 16px, 20px, 24px, 40px, and 48px, depending on context and layout needs.

You can browse the full Material Symbols icon set here to explore all available icons: https://fonts.google.com/icons

Use icons to:

  • Support navigation (e.g., menus or directional cues)
  • Represent actions (e.g., save, delete, download)
  • Indicate status (e.g., success, warning, error)
  • Reinforce content types (e.g., documents, photos)

Icons should be used sparingly and only when they improve comprehension or aid in usability.
